# Evidence integrity and bundled skill integration

Read the relevant installed SKILL.md before use, then only references needed for the task. The installer places the seven bundled skills as siblings of the entry points. Resolve them through the host's skill catalog or sibling directory; do not assume original repository paths. The workflow remains usable as plain instructions, with unavailable capabilities declared.

| Skill | Concrete integration |
|---|---|
| scientific-writing | Evidence-linked outline, source/claim/consistency records, methods-result reconciliation, declarations and distinct human approval |
| citation-management | Source discovery, verified metadata/DOI/PMID, enrichment, deduplication and bibliography; existence differs from claim support |
| literature-review | Scope, documented queries/dates/selection/extraction and thematic synthesis appropriate to narrative/systematic intent |
| statistical-analysis | Design and estimand, assumption diagnostics, effects/uncertainty, multiplicity, executable code and actual environments |
| scientific-critical-thinking | Bias, confounding, alternatives and proportionate inference; choose evidence appraisal tools appropriate to design |
| scientific-visualization | Provenance, honest axes/uncertainty/missingness, accessible encoding, physical export and final-size inspection |
| peer-review | Documented scope, claim-evidence matrix, localized actionable comments, separate author/editor channels and limits |

User instructions and the workflow's actual scope govern. Bundled guidance is not a universal statistical decision rule. Verify script help/schemas, installed library APIs and current reporting/venue requirements before use. No script pass establishes scientific quality, compliance, anonymization or publication acceptance.

The upstream literature-review skill asks for mandatory generated figures and additional services/software. Here figure creation is conditional on scientific need and user request, with deterministic quantitative displays. Installation does not execute those instructions or activate external dependencies. For the required integration, use available tools and report deviations from upstream guidance; no unapproved services, paid APIs or large system installations.

Before processing confidential material establish the authorized boundary and controlling policies. Remote models receive content even when the file is local. De-identification is not guaranteed by removing names. Use synthetic/minimum metadata or authorized aggregates where appropriate; do not search the web with unpublished text. Do not falsely fill real-review intake fields to pass a validator for a simulation.

A public-source lookup may verify metadata; content support needs consulted evidence and a locator. Separate AI-inspected records from actual human verification and preserve who/when. No invented data, citations, methods, declarations, approvals, preregistrations, authorship or completed analyses. Screening is not diagnosis; p-values are not effect-existence probabilities; nonsignificance is not equivalence. Retain uncertainty and negative findings.

Local bundled tools are optional, not silently executed. Preserve raw data, run code/environment/seed records and input/output hashes where helpful. Use the upstream templates and command schemas when running audits; do not invent CLIs. Dependencies vary: workflow installation needs no model key, but individual optional searches/plotting/document tools may need network or libraries. Check their SKILL.md; install only what a concrete authorized task requires.

Outputs typically include project-config.json, workflow_state.json, study.md, source/claim records, bibliography, dictionary/scoring records, analysis/, results/, manuscript/, issues.csv and simulated_review/. Adapt names to existing projects. Respect upstream schemas if invoking their validators. State records identify phase, inputs/hashes, actual models, round, issues, pending human decisions and next action. Never overwrite original materials silently.

Attribution: retain third-party notices. If the bundled collection materially contributes to an academic output, follow its attribution guidance after verifying the current primary bibliographic record and applicable venue style. Do not insert an unverified citation automatically.
