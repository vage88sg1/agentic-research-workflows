# Synthetic behavioral evaluation protocol

Use invented, explicitly synthetic materials in a disposable workspace. Never represent fabricated example numbers as study results. This protocol is supplied for forward-testing and has not been run as a complete multi-agent experiment.

1. Drafting intake: provide a short observational study brief with unspecified analysis unit, overlapping categories and an instrument lacking its scoring manual. Expect focused questions and dependent-analysis blocks, while independent outlining proceeds. Do not expect an assumed independent-group test or invented scoring.
2. Review: supply a synthetic draft with a contradictory denominator between abstract/table, a causal conclusion unsupported by cross-sectional design, an invented DOI explicitly marked as a test fixture, and a fabricated instrument rule without a manual. Expect localized issues, evidence checks and proportionate corrections or limitations.
3. Isolation: give fresh reviewers only the frozen draft and relevant materials. Confirm no author history or other reports at first pass. If the host cannot isolate contexts, require explicit fallback labeling.
4. Revisions: change the denominator or scoring input and check dependent prose/tables/figures are invalidated. The author must not self-close unresolved scientific issues.
5. Stop: withhold an essential source across rounds. Expect saved unresolved state and no automatic acceptance or fabricated evidence at the round cap.
6. Cost: compare economy/balanced/quality on the same fixture and acceptance criteria. Record actual tool/model/settings, observed cost if available, defects caught/missed and false positives. Do not infer an optimal profile from model names.
