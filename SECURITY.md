# Security and confidential material

This package contains instructions and optional third-party tools; installation does not sandbox them or guarantee confidentiality. Review tools before execution. Scope file access and external services using the host's actual controls.

Use only authorized material in the chosen processing environment. Local files may be sent to a remote model when read into its context. Directory separation and prompt instructions are not access-control enforcement.

Do not post sensitive research artifacts or credentials in public issues. Report vulnerabilities using a private reporting channel if enabled on the repository; otherwise ask the maintainer for a private route without including exploit secrets or confidential data. No response-time guarantee or undisclosed contact address is implied.
