# Guided-entry usability exercises

Six bounded first-turn executions were completed: three initial cases and three fresh-context repetitions after narrowing the amount of process for simple requests. Inputs were explicitly synthetic. Evaluators followed Galileo and the selected specialist instructions in isolated temporary directories, produced actual Markdown artifacts, and recorded their questions and files. They did not receive earlier generated answers. No fictional user replies were supplied.

## Observed results

Artifact counts exclude input copies, the evaluation transcript and the evaluation log. They include additional workflow state, configuration and comparison files created as part of the work.

| Case | Questions before → after | Work artifacts before → after | Useful result after correction |
|---|---|---|---|
| Begin a thesis from a study brief | 3 → 3 | 5 → 2 | A planning note and compact resumable state; scope, territory and recruitment remain genuine questions |
| Improve a supplied manuscript excerpt | 0 → 0 | 3 → 1 | The corrected Markdown alone, with original numbers, headings and qualifications preserved |
| Plan six slides for an eight-minute talk | 0 → 0 | 2 → 1 | Six slide sections with messages, notes and estimated timing totaling 480 seconds; no production-state file |

All three cases supplied a useful first artifact rather than waiting for a technical setup form. The thesis case stopped at actual missing information. Editing and slide-content requests completed without questions. The change reduced auxiliary artifacts in these examples; it does not establish a general speed or cost improvement.

The reproducible [input cases](../examples/usability) and [count record](../examples/usability/results.json) are included. Original evaluator responses remained in the temporary evaluation workspace; they are not recommended scientific examples. Numerical/structural checks and source comparisons were performed by AI, not by human reviewers.

## Changes made from the observations

- Galileo now matches process to scope: one-off edits and Markdown content do not require new project configuration, issue or state files. Existing tracked projects can still update their records.
- Drafting has an explicit scoped-edit path that skips unrelated study intake and full-project setup.
- Presentation content has an explicit path that skips theme, renderer and export setup when those outputs are not requested.
- Initial thesis planning can start with a useful note and compact state; further ledgers are created when there is substantive work to record.

## Additional citation finding

The initial and repeated slide exercises automatically inserted an academic reference found in support guidance without bibliographic verification. Its presence was labeled unverified, but it was still unnecessary for the requested talk. A separate instruction now requires primary-record verification before inserting such a reference; offline preparation omits it and keeps necessary software credit in project provenance.

An additional independent repetition after this citation-specific correction did **not** execute because the evaluator reached the host usage limit. This final instruction has structural validation, not a completed behavioral retest. The six completed executions above must not be presented as testing that final correction.

## What this evaluation does not establish

These are synthetic agent exercises, not a study with human users. Each task used sequential roles in one context. Source-checking, rendering, oral timing and real journal access were outside scope. Some evaluators could not discover optional support skills from the source-tree layout and recorded the fallback; a complete installed-profile host trial remains relevant. No model-usage telemetry, latency benchmark or cost comparison was available.

A useful next human trial is to give these same three goals to newcomers, observe whether they can find Galileo and continue from its first response, and record confusion without explaining the internal workflow structure first.
