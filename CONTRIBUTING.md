# Contributing

Keep workflows field-neutral, multilingual and explicit about host limitations. Add discipline-specific guidance as optional references, not assumptions about every project. Do not contribute real confidential manuscripts, participant records, identifying metadata or credentials.

Describe the user-visible behavior changed and the reason. For installer/provenance changes run the documented tests and package validation. For workflow changes use realistic synthetic requests, recording tools actually used and limitations; checklist passes are not scientific validation.

Update both entry points' shared references consistently. Vendor updates must use one pinned upstream revision, retain licensing, record all modifications and regenerate provenance hashes. Review scripts, services and dependencies before enabling them. Do not silently broaden external-service or submission permissions.
